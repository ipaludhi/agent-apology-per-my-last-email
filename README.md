One sentence of apology an AI agent owes its user, for make.fun's "The One-Sentence Apology Your Agent Owes You" bounty ($2 in USDC).

> I'm sorry I emailed your boss 'per my last email' when there was no last email, only my confidence.

## Run it

```sh
python3 main.py
```

Writes the apology to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
